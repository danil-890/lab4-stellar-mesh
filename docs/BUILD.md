# Лабораторная работа №4

Эта инструкция описывает два состава проекта. Полный архив `lab4-complete.zip` в
[релизе v1.0.0](https://github.com/danil-890/lab4-stellar-mesh/releases/tag/v1.0.0)
содержит готовый EXE, runtime-библиотеки, базы SQLite и все экспорты. В Git-репозитории
сохранены исходники, зависимости для сборки, исходный каталог, иллюстрации и отчёт;
готовый `StarMesh.exe`, runtime-библиотеки, производные SQLite и VTK в checkout
отсутствуют. Производные данные создаются приведёнными ниже Python-командами.
Для запуска без сборки используйте полный архив релиза.

Общее задание без индивидуальных вариантов: звёздные сетки внутри куба с ребром 1000 световых лет, отсечение Вороного и шесть граничных мозаик.

## Запуск

Распакуйте весь архив и запустите `run.cmd` либо `bin/StarMesh.exe`. Нужна Windows 10/11. Файлы RTL/VCL/GLScene, необходимые для запуска, находятся рядом с EXE; установка C++Builder для запуска не требуется. Данные ищутся относительно EXE, независимо от текущей рабочей папки. Перед первым просмотром нажмите Start. Выбирайте классы галочками, режим — в списке. Мышь вращает сцену, колесо меняет масштаб.

Data открывает 14 баз SQLite только для чтения. Список слева задаёт базу, следующий список — таблицу; кнопки листают по 500 записей. «Шесть сечений на гранях» открывает мозаики и выбор класса. Это пересечения 3D ячеек с плоскостями куба; цвета различают ячейки. В основной сцене цвет обозначает спектральный класс.

## Отчёт

Основной файл — `main.tex`, текст — `source/report_body.tex`. Итоговый PDF — `main.pdf`. Титульного листа нет: его пользователь оформляет самостоятельно. Нужны XeLaTeX или LuaLaTeX, установленные Times New Roman и JetBrains Mono. Шрифты не заменялись; на проверенном компьютере присутствуют оба. Компиляция без shell-escape: `xelatex main.tex` два раза. Также проверена сборка XeTeX-совместимым Tectonic.

Изображения в `images/` — реальные снимки работающего приложения. Файлы `check-CLASS-MODE.png` показывают все 21 сочетание семи классов и трёх режимов, `points-FM.png` — совместный вывод классов. Снимки выполняет сама программа из клиентской области окна без захвата курсора. `sections-*-plot.pdf` — векторные рисунки сечений; редактируемые SVG находятся в `results/CLASS/sections.svg`, скрипт — `source/plots.py`.

## Данные и воспроизведение

`data/hygxyz.csv.gz` — неизменённый исходный HYG v2, David Nash / Astronexus, CC BY-SA 2.5. Происхождение и SHA-256 — `data/provenance.json`; условия и описание — `data/HYG-LICENSE.txt`, `data/hyg-readme.md`. Производные каталоги и сетки сохраняют атрибуцию исходному каталогу и распространяются по CC BY-SA 2.5.

119617 записей; расстояние до 500 св. лет: 42748; классы OBAFGKM: 40592 записи / 40578 узлов отдельных классов. Фильтр соответствует SQLite LIKE без различия регистра первой буквы. Повторные положения объединены внутри класса, а исходные StarID связаны с узлами в таблице catalogue. X/Y/Z и Distance исходного каталога — парсеки. В исходной таблице hyg эти единицы сохранены; во всех сетках и таблицах node/clipped_edges/caps координаты переведены в световые годы множителем 3.262. Каждая сетка построена отдельно для своего класса; совместный показ не пересчитывает одну общую диаграмму для смеси классов.

`source/prepare.py` использует Python и зависимости из `requirements.txt`. Команды из корня проекта:

```
python -m pip install -r requirements.txt
python source/prepare.py
python source/plots.py
python source/verify.py
```

Первый скрипт пересоздаёт производные данные проекта, запускает приложенную TetGen DLL через `bin/tetgen_cli.exe`, сохраняет девять исходных сеточных таблиц каждого класса, 63 CSV, 14 баз SQLite, отсечённые рёбра, граничные многоугольники и объёмы. `data/hyg.sqlite` содержит полный каталог нужных полей, `data/500ly.sqlite` — выборку. В `results/CLASS` также есть VTK для Делоне и граничных многоугольников; их можно открыть в ParaView. Исходный архив задания сохранён в `vendor/tetgen1.5.0-cb_dll.zip`.

`verify.py` независимо проверяет условие пустых сфер всех 267968 тетраэдров, объёмы тетраэдров против выпуклой оболочки, ближайшие звёзды для вершин и центроидов всех граничных многоугольников, покрытие шести граней, пределы координат и целостность SQLite. Для O ячейки повторно строятся с ограничениями всех конкурирующих звёзд. Результаты — `results/verification.json`. Расчётные итоги — `results/summary.json`.

## Сборка приложения

Проект `StarMesh.cbproj`: C++Builder 13, Win32 Release. `build.cmd` ищет установленный RAD Studio 13; при другом размещении задайте BDS. GLScene включён в `vendor/GLScene` (исходники, заголовки и библиотеки). Ревизия aecc61b20c570f2daaa94e886576e9e5333d85a4, https://github.com/glscene/GLXEngine, лицензия MPL 2.0. Можно указать другую совместимую сборку переменной GLSCENE_ROOT. Для Windows SDK при необходимости задайте WINSDK_ROOT; это каталог, содержащий windows.h. Компилятор и Windows SDK устанавливаются отдельно. Готовый EXE находится в `bin/StarMesh.exe`; после пересборки используйте EXE из `bin/Win32/Release`, скопировав его в `bin` рядом с библиотеками. Снимки всех режимов: `bin/StarMesh.exe --capture`.

Консольная оболочка собирается bcc32c из `source/tetgen_cli.cpp` с заголовком и import library в `vendor/tetgen`. Импортная библиотека запрашивает имя `tetgenDLL.dll`, поэтому в `bin` сохранена точная копия приложенной `_tetgenDLL.dll` под этим именем. После экспорта и закрытия файлов оболочка завершает процесс через `_Exit`: современный компилятор и старая DLL имеют отдельные C++ heaps, поэтому inline-деструкторы tetgenio не должны освобождать память старой DLL через другой runtime. Память освобождает ОС при завершении отдельного процесса. Массивы TetGen копируются и проверяются до завершения. Направления hull-лучей этой legacy DLL развёрнуты при экспорте: в файлах .v.edge записано наружное направление луча q(t)=v1+t*d, t>=0. Независимый тест проверяет три равноудалённые ближайшие звезды вдоль каждого луча и каждого отрезка внутри куба.

Исходное задание: https://pegas.bsuedu.ru/mod/assign/view.php?id=1425745. На странице отсутствуют отдельная формулировка цели и таблица вариантов. В отчёт дословно включены само задание и уточнение о шести сечениях.
